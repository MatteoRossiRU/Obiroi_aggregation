# Ooceraea biroi aggregation

This repository contains the data and analysis code associated with the study:

Rossi et al., A hydrocarbon pheromone mediates group cohesion.

The repository includes experimental data and scripts used for data processing, statistical analyses, and figure generation presented in the manuscript.

The code is written in a combination of R, MATLAB, and Python.

# Repository structure

- `data/`: Experimental data used in the analyses.
- `script/`: Code for data processing, statistical analyses, and figure generation.

The scripts are organized according to the corresponding analyses and figures in the manuscript.
